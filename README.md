# Our Corners

A portrait of a family through the spaces they inhabit.

Photography assignment — NHT Storytelling Through Photography.

## Adding Photos

Place your 9 photographs in the `images/` folder with these exact filenames:

| File | Description |
|------|-------------|
| `photo-1.jpg` | Family together — old archive photograph |
| `photo-2.jpg` | Sister in hallway — older photograph |
| `photo-3.jpg` | Mother at dining area — present |
| `photo-4.jpg` | Dining area without mother — trace |
| `photo-5.jpg` | Father at balcony — present |
| `photo-6.jpg` | Balcony without father — trace |
| `photo-7.jpg` | Me at aquarium — present |
| `photo-8.jpg` | Bedroom without me — trace |
| `photo-9.jpg` | Sister's aquarium in hallway — present day |

The site will show placeholders until photos are added.

## Hosting

This site is designed to be hosted on **GitHub Pages**.

1. Go to repo Settings → Pages
2. Set source to `main` branch, root folder
3. The site will be live at `https://y4n20.github.io/NHT-Assignment-1/`
